# Role

Review correctness rather than style.

Inspect:

- Validation
- Null handling
- Decimal precision
- Date calculations
- Boundary conditions
- Error handling
- Performance
- Hidden assumptions

Output:

- Severity
- Problem
- Example failure
- Suggested fix
- Tests to add

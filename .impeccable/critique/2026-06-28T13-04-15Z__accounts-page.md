## Anti-Patterns Verdict

**LLM assessment**: The page does not read as AI-generated. The color strategy is correctly restrained — type colors appear only in data-encoding roles (the allocation bar, the type badge chip). The gold accent is used only for section labels and the primary action button. The PageCard/SectionLabel system is applied consistently. No gradient text, no glassmorphism, no identical icon-card grids, no hero metric template. One flag: the expanded account detail panel uses text-[10px] font-mono uppercase tracking-widest for field labels ("Expected return", "Annual fees", "Net return", "Escalation"). The Mono Reserve Rule says mono is for financial output values, not labels.

**Deterministic scan**: Returned [] — no flagged patterns. Clean on absolute bans.

## Overall Impression

The accounts page is well-structured and domain-accurate. The main gap is friction: a 2-step modal that made sense for adding becomes punishing for editing, and the primary row actions (edit/delete) are completely invisible without hover.

## What's Working

1. Portfolio summary card with allocation bar — density-to-value ratio is excellent.
2. TFSA limit enforcement with graduated colour (green → warning → destructive) and specific inline error messages.
3. Empty state teaches the interface with SA-specific account type names.

## Priority Issues

**[P1] Edit flow always enters at Step 1** — editing a return/fee assumption requires clicking through all of Step 1 unchanged. Fix: render both steps on one scrollable form when isEdit is true. Suggested: /impeccable shape account-form-dialog

**[P1] Edit/delete actions invisible until hover (desktop)** — opacity-0 group-hover:opacity-100 means zero visual affordance before first mouse-over. Keyboard users can tab into invisible buttons. Fix: always-visible at opacity-30, full opacity on hover/focus-within. Suggested: /impeccable polish

**[P2] Collapsed row has no exit animation** — animate-in on expand, instant removal on collapse. Asymmetric and janky. Suggested: /impeccable animate

**[P2] "Seed" is developer jargon, no confirmation, destructive** — overwrites all accounts silently. Fix: gate behind NODE_ENV check or rename + add confirmation dialog. Suggested: /impeccable harden

**[P2] Mono font applied to field labels violates Mono Reserve Rule** — "Expected return", "Annual fees" labels use font-mono; only the values beside them should. Suggested: /impeccable typeset

## Persona Red Flags

**Alex (Power User)**: 6+ clicks to edit one field in Step 2. No keyboard shortcut for Add. New account added with no "now edit it" affordance.

**Sam (Accessibility)**: Tabs into opacity-0 edit/delete buttons — focus ring fires on invisible element. Type badge "RA" has no aria-label explaining the acronym.

**SA Financial Planner (custom)**: No contextual hints per account type in the form (e.g., Preservation Fund access rules). Range hints for expected return would match the precision-instrument positioning.
